# Сайт «Вертел Караманов» — что сделано и как жить дальше

Живая версия: https://albubnov123-hash.github.io/vertel-karamanov/
Репозиторий: https://github.com/albubnov123-hash/vertel-karamanov
Предыдущая (тёмная) версия дизайна сохранена тегом `v1-classic` — откатиться можно так:
`git checkout v1-classic -- . && git commit -m "откат" && git push`.
Локальная копия: /root/vertel_karamanov/site

## Что внутри

    index.html    — вся главная в стиле Apple: тёмный герой с видео, светлые
                    секции, карточки трёх моделей, характеристики таблицей,
                    лента кадров, доставка, FAQ, контакты
    styles.css    — вся вёрстка и типографика, один файл, без сборки
    app.js        — липкая шапка, мобильное меню, появление блоков, аккордеон
    policy.html   — политика конфиденциальности (текст ИП Караманов, перенесён
                    с прежнего сайта, оформление новое)
    404.html      — страница «не найдено»
    assets/img    — продуктовые фото и кадры из ваших шортсов
    assets/video  — hero.mp4 (десктоп), hero-mobile.mp4 (телефон), постеры
    assets/fonts  — Oswald + Montserrat (variable, лежат локально)

Стек намеренно «скучный»: статический HTML/CSS/JS. Нет CMS, нет базы, нет
зависимостей — открывается на любом хостинге и не ломается от обновлений.
Вес страницы ~11 МБ вместе с видео (сам HTML+CSS+JS — 47 КБ).

## Как править контент

- Цены и характеристики — прямо в index.html, ищутся по словам «23 207 ₽» и т.п.
- Текст в блоках — обычный HTML внутри `<section>`.
- Фото моделей: assets/img/model-battery.jpg, model-big.jpg, model-compact.jpg
  (1000×750, 4:3). Заменили файл — вёрстка не поедет.
- Чтобы передеплоить: `cd site && git add -A && git commit -m "правки" && git push`.
  GitHub Pages обновится за минуту.

## Как повесить домен vertelkaramanov.ru

Домен сейчас на DNS Tilda (ns1/ns2.tildadns.com) — именно поэтому старый сайт
и отдавал 404: домен есть в аккаунте Tilda, а проект не опубликован.

Вариант A (оставить DNS в Tilda):
1. В Tilda, в настройках домена, добавить DNS-записи:
   A     @      185.199.108.153
   A     @      185.199.109.153
   A     @      185.199.110.153
   A     @      185.199.111.153
   CNAME www    albubnov123-hash.github.io
2. В GitHub: репозиторий → Settings → Pages → Custom domain → vertelkaramanov.ru
   → Save, затем включить Enforce HTTPS (сертификат выпустится сам за 5–30 мин).

Вариант B (если Tilda не даёт править записи): в личном кабинете REG.RU
сменить NS на Cloudflare (бесплатно), там повторить записи из пункта 1.

Google/Яндекс переиндексируют сайт за 1–3 недели; старые адреса /policy и
/delivery лучше перенаправить — для этого достаточно добавить в index.html
редиректы или файл _redirects, если хостинг их поддерживает.

## Что осталось за кадром

- Четыре подстраницы старого сайта (доставка, производитель, рецепты,
  сертификат) в архив не попали — их содержание частично перенесено в блоки
  «Доставка» и «Технология». Если нужны отдельные страницы (например, «Рецепты»
  или скан сертификата) — делаются за один заход.
- Формы заказа нет: заказ идёт по телефону/WhatsApp и на маркетплейсы.
  Если нужна форма с заявками — нужен бэкенд или сервис вроде Formspree.
- Аналитика не подключена; для рекламы понадобится Метрика.
